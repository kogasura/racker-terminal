## v1.4.0

### 新機能
- **設定画面でバージョン確認 / 手動アップデートチェック**: 設定ダイアログに「バージョン情報」セクションを追加。現在のアプリバージョンを表示し、「アップデートを確認」ボタンから手動で更新チェックできる。更新がない場合は「最新バージョンです」と表示、利用可能な更新が見つかった場合は従来通りバックグラウンドでダウンロードし、TitleBar の `↑` バッジから再起動できる。すでにダウンロード済みの状態でボタンを押すと即座にアップデートダイアログが開く

### 既知の制約
- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能
