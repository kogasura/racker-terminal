## v1.9.12

**ドライブを右クリックしても「Racker Terminal で開く」が出るようになりました。あわせて、Windows 11 の新しい右クリックメニューへの対応を仕込んであります。**

### 新機能

- **ドライブの右クリックに対応**: 「PC」から `C:` などのドライブを右クリックしたときにも「Racker Terminal で開く」が出るようになりました。これまではフォルダとフォルダ背景だけでした。

- **Windows 11 の新しい右クリックメニューへの対応（準備）**: Windows 11 で右クリックした直後に出るメニューの第一階層に「Racker Terminal で開く」を出すための仕組みを入れました。Windows ターミナルや VS Code がそこに出ているのと同じ方式（MSIX の shell extension）です。

  **この更新では、まだ第一階層には出ません。** この方式はパッケージへのコード署名が必須で、証明書がまだ無いためです。証明書が用意できた時点の更新で有効になります。それまでは**これまでどおり「その他のオプションを表示」（`Shift+F10`）の中に出ます** — 登録に失敗しても従来の登録はそのまま行われるので、右クリックから開けなくなることはありません。

### 補足

- Windows 10 には新しい右クリックメニュー自体が存在しないため、この対応は Windows 11 でのみ動きます。インストーラーが Windows のビルド番号を見て判断します。
- 新しいメニューの側では、仕様上ドライブを対象にできません。そのためドライブの右クリックは、従来方式の登録で対応しています。
- 右クリックから開いたときの挙動はこれまでと変わりません。Racker Terminal が起動中なら、ウィンドウを増やさず既存のウィンドウにタブを足して前面に出します。既定のお気に入りを設定していれば、そのシェル・引数・環境変数を引き継いだうえで作業フォルダだけを差し替えて開きます。
