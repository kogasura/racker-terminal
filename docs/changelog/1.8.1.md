## v1.8.1

**このリリースは不具合調査のためのものです。** v1.8.0 以降で報告されている「画面が真っ白になってフリーズする」問題の原因を特定するために、エラー内容を画面に出せるようにしました。問題そのものはまだ直っていません。

### 変更点

- **描画エラーを画面に表示するようにしました**: これまでは描画中にエラーが起きるとウィンドウが真っ白になるだけで、何が起きたのか分かりませんでした。今後はエラーメッセージと発生箇所が画面に出ます。「コピー」ボタンで内容をクリップボードに取れるので、そのまま報告に使えます。

### 内部の変更（動作に影響しないもの）

- rustfmt / clippy / ESLint による自動チェックを導入しました。関数の長さと複雑度に上限を設けています。
- 上記チェックに合わせて内部のコードを整理しました。動作を変えない範囲の組み替えです。
- テストを追加しました（TypeScript 639 件 / Rust 47 件）。ターミナルの入出力、キーボードショートカット、ドラッグ&ドロップ、画面の描画を対象にしています。
- GitHub Actions による自動チェックを追加しました。

### 既知の問題

- **操作していると画面が真っ白になり、フリーズすることがあります。** 原因は未特定です。発生したらエラー画面の内容をお知らせください。
- Windows 環境で、PTY セッションの後始末時に内部スレッドの終了待ちが返らないことを確認しています。上記フリーズとの関連を調査中です。
- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
