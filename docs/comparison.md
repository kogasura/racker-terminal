# 他のターミナルとの違い

|  | **Racker** | Windows Terminal | WezTerm | [herdr](https://herdr.dev/) |
|---|---|---|---|---|
| Claude Code の自動起動 | ✅ | ❌ | ❌ | ❌（手動で起動） |
| 再起動後のセッション再開 | ✅ claude の続きから | ❌ | ❌ | ✅ サーバ常駐で維持 |
| エージェントの待ち状態通知 | ✅ タブが光る | ❌ | ❌ | ✅ 状態サイドバー |
| プロジェクト別ワンクリック起動 | ✅ お気に入り | △ プロファイル | △ 設定ファイル | ✅ |
| 再起動後のタブ構成復元 | ✅ | ❌ | ❌ | ✅ |
| WSL パスの自動変換 D&D | ✅ | ❌ | ❌ | — |
| 設定方法 | **GUI ダイアログ** | JSON | Lua | TOML / CLI |
| ペイン分割 | ❌ | ✅ | ✅ | ✅ |
| SSH / リモート | ❌ | — | ✅ | ✅ |
| 対応 OS | Windows のみ | Windows | クロスプラットフォーム | Linux / macOS / Windows (beta) |

**向いている人** — Windows + WSL で Claude Code を複数プロジェクト並行で回している / tmux のキーバインドを覚える気はなくマウスとサイドバーで完結させたい / 設定ファイルを書かずに GUI で済ませたい。

**向いていない人** — ペイン分割が必須 / SSH 先で使いたい / macOS・Linux も使う / ターミナルを細かくカスタマイズしたい（Racker は設定項目を意図的に絞っています）。SSH 越しに複数エージェントを回したいなら [herdr](https://herdr.dev/) の方が適任です。
