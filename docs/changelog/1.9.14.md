## v1.9.14

**画面下のコンテキスト表示が、使っているモデルの本当の上限で出るようになりました。**

### 修正

- **コンテキストの残りが実際より少なく見えていた問題**: 画面下のステータスバーは、コンテキストの上限を一律 200k とみなして表示していました。Opus 5.5 / Opus 5 / Fable など、いま主に使われているモデルの上限は 1M なので、たとえば 120k 使った時点で本当は 12% なのに「120k / 200k (60%)」と出ていました。

  これからは、使っているモデルから上限を判断します。Opus / Sonnet 4.6 以降、Haiku 5 以降、Fable / Mythos は 1M、それより前のモデル（Haiku 4.5 など）は 200k で表示します。モデル名に `[1m]` が付いている場合は常に 1M です。

### 新機能

- **外から「今すぐ更新を確認」を頼めるように**: `racker-terminal.exe --check-update` を実行すると、起動中の Racker Terminal が 1 時間ごとの定期確認を待たずに、新しい版の確認とダウンロードを始めます。ウィンドウは前面に出ません。Claude Code がリリース直後にこれを使い、新しい版をすぐ手元に届けます。

### 補足

- 判別できないモデル名のときは、これまでどおり 200k で表示し、使用量がそれを超えた時点で 1M に切り替えます。
- 更新の適用（再起動）は、これまでどおり「↑」バッジを押したときだけ行われます。

### 既知の問題

- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
