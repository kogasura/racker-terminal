## v1.6.0

### 新機能
- **お気に入りの WSL 専用フィールド**: Shell に `wsl.exe` を選ぶと、「WSL ディストリビューション」（ドロップダウン）と「作業ディレクトリ（Linux パス）」だけで設定できるようになりました。`-d` や `--cd` を手書きする必要はありません（起動引数は自動で組み立てられます）。インストール済みの distro が取得できない場合は手入力に切り替わります。

### 改善 / 修正
- **WSL での Claude Code 自動起動を確実化**: WSL タブで「Claude Code を自動起動」を ON にしたとき、シェルへコマンドをタイプ送信する方式をやめ、claude を直接起動する方式に変更しました。WSL の起動が遅い環境（コールド起動など）でも取りこぼさず確実に起動します。claude を終了したあとは通常のログインシェルに戻るため、タブはそのまま使い続けられます。
- 手動で起動引数を細かく指定したい場合のために、お気に入り編集画面で簡易フォームと手動引数モードを切り替えられます。

### 既知の制約
- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
- 「Claude Code を自動起動」は設定後に新しく開いたタブから有効です（既存のお気に入り／すでに開いているタブには遡及しません）。
