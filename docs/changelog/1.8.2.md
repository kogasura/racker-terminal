## v1.8.2

**v1.8.0 以降で報告されていた「画面が真っ白になってフリーズする」問題を修正しました。** v1.8.1 は原因調査用のリリースでしたが、原因が特定できたのでここで直しています。

### 修正

- **操作中にウィンドウが固まる問題を解消しました**: タブを閉じたとき、Claude のセッション情報を読むとき、PR の状態を取りに行くときなど、時間のかかる処理が**ウィンドウの描画と同じ場所で実行されていた**のが原因でした。処理が返ってくるまで画面が一切更新されず、数秒続くと Windows に「応答なし」と判断されてアプリごと終了させられていました。

  とくに影響が大きかったのは次の 3 つです。

  - **タブを閉じたとき**: ターミナルの後始末が終わるまで、ウィンドウ全体が待たされていました。この後始末は Windows のコンソール基盤（ConPTY）の都合で、なかなか返ってこないことがあります。
  - **2 秒ごとの Claude セッション確認**: WSL の中を覗きに行く処理で、WSL が停止中だと 1 回あたり数秒止まっていました。何も操作していなくても定期的に固まる原因です。
  - **30 秒ごとの PR 状態の取得**: `gh` コマンドのネットワーク通信が終わるまで待っていました。

  これらをすべてバックグラウンドで動かすようにしたため、時間のかかる処理があっても画面は動き続けます。

- **タブを閉じてもターミナルの裏方プロセスが残り続ける問題を修正しました**: タブを閉じる際の後始末の手順が誤っており、Windows のコンソール基盤（ConPTY）を閉じる処理が返ってこなくなっていました。その結果、タブを閉じても `OpenConsole.exe` というプロセスが残り、使うほどにメモリを圧迫していました。正しい順序に直したことで、後始末は 0.1〜0.3 秒程度で完了するようになりました。

  ※ これまでアプリが「応答なし」で強制終了されるたびに、この残骸が溜まり続けていました。**一度 Windows を再起動すると、溜まっていたぶんがまとめて解消されます。**

- **シェルを終了したときにタブが終了を検知できないことがある問題を修正しました**: `exit` などでシェルを終えた瞬間のタイミングによっては、終了の通知が取りこぼされていました。

### 内部の変更（動作に影響しないもの）

- ターミナルの後始末を専用スレッドに移し、画面の処理を巻き込まないようにしました。
- これまで「Windows では固まるため」という理由で無効化されていたターミナルの統合テスト 4 件を有効化しました。無効化の理由になっていた不具合自体が、今回直したものでした。
- 「タブを閉じる処理が画面を止めていないか」「開閉を繰り返しても詰まらないか」を監視するテストを追加しました。再発したらテストが落ちます。

### 既知の制約

- 開いた直後のタブをすぐ閉じた場合に限り、裏方プロセスの後始末が完了しないことがあります（Windows 側の挙動で、こちらからは制御できません）。残ったぶんはアプリ終了時に OS が回収します。

### 既知の問題

- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
