## v1.5.0

### 新機能
- **Claude Code タブの自動起動 & セッション再開**: お気に入りに「Claude Code を自動起動」設定を追加。ON にしたお気に入りから開いたタブでは `claude` が自動で起動し、アプリを再起動してタブが復元される際に**前回の claude セッションの続きから自動で再開**します（タブごとに専用セッションを保持）。セッション名はタブ名／作業フォルダ名から自動付与されます。`claude` が PATH にある環境が前提です。

### 改善 / 修正
- **端末サイズずれの修正**: ウィンドウを拡大した直後やIMEで日本語を確定した直後に、端末がペインから右にはみ出したり下部に空白ができることがある不具合を修正しました。

### 既知の制約
- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
- 「Claude Code を自動起動」は設定後に新しく開いたタブから有効です（既存のお気に入り／すでに開いているタブには遡及しません）。
