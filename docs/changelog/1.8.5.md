## v1.8.5

**バックグラウンドにいる間の無駄な処理をなくしました。** v1.8.4 に続く省電力の改善です。

### 改善

- **ウィンドウを見ていない間は PR の状態を取りに行かなくなりました**: タブに出る PR バッジのために、これまでは 30 秒ごとに `git` と `gh` を実行していました。他のアプリで作業している間も同じように動いていましたが、見ていない画面のバッジを更新しても気付きようがなく、ネットワーク通信だけが残っている状態でした。

  racker のウィンドウが前面にある間だけ取りに行くようにしました。**別のアプリに切り替えている間は完全に止まり**、racker に戻った時点ですぐ取り直すので、見るときには最新になっています。

  実測で、バックグラウンドの 100 秒間に起動されるプロセスが 0 件になりました（従来は 90 秒あたり 5 件）。ノート PC では、そのたびにネットワークが起きるのを避けられます。

### 変わらないもの

- PR バッジの内容は変わりません。racker に戻ってから約 2 秒で最新になります。
- Claude の状態通知は**これまでどおり**バックグラウンドでも動きます（別のアプリで作業している間に気付けることが目的の機能のため、止めていません）。

### 内部の変更（動作に影響しないもの）

- CPU が混雑しているときに不安定だったテスト 2 件を修正しました。判定の甘さではなく、測り方（無関係な処理時間まで測っていた点、負荷に左右される絶対値で判定していた点）を直しています。

### 既知の問題

- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
