## v1.9.5

**Claude Code が提示した画像やファイルを、Ctrl+クリックで開けるようになりました。**

### 新機能

- **Claude の応答に出てくる画像・ファイル参照が開けるようになりました**: これまでは `[img] …(image)` のようなテキストやただのパス文字列にしかならず、成果物を確かめる手立てがありませんでした。今回から下線付きのリンクになり、**Ctrl を押しながらクリック**（Mac のキーボードでは Cmd+クリック）で開けます。

  開き方はファイルの種類で切り替わります。

  - **画像・PDF・Markdown・HTML・CSV などの閲覧系**: いつものアプリ（フォトビューア等）でそのまま開きます。
  - **ソースコードや実行ファイル（.exe / .bat / .js / .py など）**: 誤って実行してしまわないよう、エクスプローラーでファイルの場所を表示するだけに留めます。

  WSL タブの `/mnt/c/...` 形式のパスにも対応しています。

- **Web の URL も同じ操作で開けます**: これまでどおり Ctrl+クリックです。修飾キーなしの単純クリックでは何も起きません（プロンプト編集中の誤クリック対策）。

### 補足

- この機能は、シェル内のツールに「この端末はリンク対応」と伝える標準的な環境変数（`FORCE_HYPERLINK=1`）で実現しています。タブやお気に入りの env に `FORCE_HYPERLINK=0` を設定すれば、そのタブだけ無効化できます。
- 画像そのものをターミナル内に描画する機能（インライン表示）は今回は含まれていません。

### 既知の問題

- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
