## v1.9.18

**左のサイドバーを隠せるようになりました。ウィンドウを画面の半分などで使うときも、ターミナルを広く使えます。**

### 新機能

- **サイドバーの表示 / 非表示**: タイトルバー左端のボタンを押すと、左のサイドバー（お気に入り・クイックアクセス・グループ）が隠れ、ターミナルが窓の幅いっぱいに広がります。もう一度押すと元に戻ります。
  - キーボードでは `Ctrl+Shift+B` で切り替えられます。
  - 隠したかどうかは保存され、再起動しても隠したままになります。

### 補足

- サイドバーを隠している間は、グループの切り替えや設定（⚙）は使えません。使うときはいったん表示してください。
- `Ctrl+B`（Shift なし）は Claude Code が使うキーなので、そのままターミナルに届きます。

### 既知の問題

- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
