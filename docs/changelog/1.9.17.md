## v1.9.17

**テーマに「動く背景」が付きました。Claude Code のカスタムテーマと同じ 20 のシーンが、racker の窓の後ろで動きます。**

### 新機能

- **動く背景付きのテーマ**: 設定のテーマに、背景が動くテーマを 20 種類足しました。上から見たラグーンを泳ぐウミガメ、雪の降る松林、点字の星空、発車案内板などです。ライト向けとダーク向けがあります。
  - 選ぶと、画面の枠とターミナルの配色も、そのシーンに合う色に変わります。
  - サイドバー・タブ・タイトルバーなどはすりガラスになり、背景が透けて見えます。ターミナルは文字が読めるよう、濃いめに重ねます。
  - シーンは Anthropic の公式プラグイン theme-examples（Apache-2.0）から移植しました。

- **選びやすくなった設定画面**: テーマはカードの一覧から選べます。カードを押すと、その場で窓に試しに表示されます（ターミナルの配色も変わります）。「保存」で確定し、「キャンセル」か Esc で元に戻ります。

- **背景を動かす**: 設定の「背景を動かす」を外すと、背景が止まります。

- **自分で背景を作る**: themes フォルダに SVG を置き、テーマの JSON から指定すると、自作の背景になります。設定画面の「Claude でテーマを作る」から claude に頼めば、作り方の説明を読んで作ってくれます。コンテキストの使用量や、claude が動いているかどうかに合わせて変わる背景も作れます。

### 変更

- **お気に入りのテーマが窓全体に効くように**: お気に入りで指定したテーマは、これまでターミナル部分の配色だけを変えていました。これからは、そのタブを開いている間、窓全体（背景・画面の枠・ターミナル）がそのテーマになります。お気に入りの編集画面の欄の名前も「ターミナルの配色」から「テーマ」に変わりました。

### 補足

- 背景のアニメーションは 1 秒に 30 コマまでに抑え、窓を最小化している間は止まります。Windows の「アニメーション効果」をオフにしている場合も止まります。
- 背景付きのテーマでは、透明度の設定は使いません（配色だけのテーマには、これまでどおり効きます）。
- 明るいシーンでは、claude 側でも `/theme` で light を選ぶと読みやすくなります。

### 既知の問題

- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
