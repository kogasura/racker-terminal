## v1.8.0

Claude Code を回すための機能をまとめて強化しました。**タブの見た目が変わります**（縦のフォルダ + 横タブ）。

### 新機能

- **レイアウト変更: 縦にフォルダ、横にタブ**: 左サイドバーにはグループ（フォルダ）だけが縦に並び、選択したグループのタブが画面上部に横並びで表示されるようになりました。タブが増えてもサイドバーが縦に伸び続けません。タブが見えなくなる代わりに、各グループ行に「配下タブの状態」とタブ数が集約表示されます。
- **Claude の状態がタブに出る**: タブのステータスドットが Claude の状態に応じて変わります。**応答待ち（青・速い明滅）/ 実行中（オレンジ）/ 完了（緑）/ 待機中（無印）**。Claude Code 自身が申告している状態を読んでいるので、画面の見た目に頼った推測ではありません。応答待ちのときは tooltip に理由も出ます。状態はグループ行にも集約されるので、いま見ていないフォルダの分まで気付けます。
- **デスクトップ通知**: 表示中でないタブの Claude が応答待ちになったとき、または処理を終えたときに Windows の通知が出ます。racker のウィンドウを見ていなくても気付けます（設定の ⚙ から切れます。いま開いているタブは通知しません）。
- **手動で起動した Claude も追跡**: 「Claude Code を自動起動」を使っていないタブでも、自分で `claude` と打ったセッションを検出して結びつけます。再起動後に同じセッションから再開できます。
- **再起動しても画面が残る**: タブの表示内容（直近 1000 行）を保存し、再起動時に書き戻すようになりました。区切り線が入るので、どこまでが前回の出力かが分かります。プロセスまで復活するわけではありません。
- **PR の状態がタブに出る**: タブの作業ディレクトリが git リポジトリなら、現在のブランチに対応する PR の番号バッジを表示します（オープン / マージ済み / クローズ / 下書きで色が変わります）。クリックでブラウザで開きます。`gh` コマンドが使える環境でのみ動作します。
- **エクスプローラー右クリックに「Racker Terminal で開く」**: フォルダを右クリックしてそのまま開けます。
- **フォルダを選んで臨時のタブを開く**: サイドバー下部のボタンから、お気に入りに登録せずフォルダを選んでタブを開けます（Windows / WSL 両対応）。

### 改善 / 修正

- **長時間使用でアプリが応答しなくなる問題を解消**: WebGL context のリークと、大量出力時に UI が詰まる問題を修正しました。非アクティブなタブの WebGL は休止し、出力が溜まりすぎたときは読み取りを一時停止します。
- **再起動直後にタブが選択されない問題を修正**: これまで復元後はどのタブもアクティブでない状態になっていました。

### 既知の制約

- Authenticode コード署名は未対応のため、SmartScreen 警告は引き続き出ます。「詳細情報」→「実行」で続行可能。
- scrollback の復元は**表示のみ**です。プロセスは復活しないため、区切り線から下が新しいセッションになります。
- PR バッジは Windows パスの作業ディレクトリでのみ動作します（WSL タブは対象外）。
- 「Claude Code を自動起動」「権限プロンプトをバイパス」は設定後に新しく開いたタブから有効です（すでに開いているタブには遡及しません）。
